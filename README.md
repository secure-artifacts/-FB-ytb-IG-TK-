📸 智能截图助手 Pro v2.0
> 支持多平台一键截图，自动归类保存至 Google Drive，并同步记录到 Google Sheets。
---
✨ 功能特点
多平台支持：Facebook · YouTube · Instagram · TikTok · Pinterest · Behance · Dribbble · Flickr
两种截图方式：🎥 一键截取当前视频画面 / ✂️ 自由框选任意区域
自动归档：截图按「日期 / 视频」自动创建文件夹存入 Google Drive
表格同步：自动将截图链接、日期、备注等写入 Google Sheets，图片通过 Drive 缩略图实时加载，不占 Sheets 存储空间
字段开关：可自由开关「下载链接、打开位置、备注、来源链接」四个字段
横/竖排布局：横排（同分类数据左右扩展）/ 竖排（新数据从上插入，旧数据下移）
分类管理：自定义分类标签，支持一键复制分类列表
配置导出/导入：一键导出 JSON 配置，好友粘贴即可同步全部设置

🚀 安装方法
第一步：安装 Chrome 扩展
下载并解压本项目文件夹
打开 Chrome，访问 `chrome://extensions`
右上角开启「开发者模式」
点击「加载已解压的扩展程序」，选择解压后的文件夹
工具栏出现 📸 图标即安装成功
第二步：部署 Google Apps Script
打开 Google Apps Script，点击「新建项目」
删除编辑器里的默认代码，将 `apps_script.gs` 的全部内容粘贴进去
点击右上角「部署 → 新建部署」
类型选「Web 应用」
设置如下：
执行身份：以我自己身份执行
访问权限：所有人（含匿名用户）
点击「部署」，复制生成的 Web 应用 URL（格式：`https://script.google.com/macros/s/.../exec`）
第三步：配置插件
点击工具栏的 📸 图标，在「⚙️ 配置」标签填写：
字段	说明
GAS 部署链接	第二步复制的 Web 应用 URL
谷歌表格 ID	打开目标表格，复制浏览器地址栏链接粘贴即可
Sheet 名称	留空使用第一个 Sheet，或填写底部标签名称（区分大小写）
网盘文件夹 ID	打开 Drive 目标文件夹，复制地址栏链接粘贴即可
> ⚡ 配置实时保存，无需点击保存按钮
第四步：开始使用
打开任意支持的平台网页并刷新页面
页面右侧出现悬浮工具栏
点击 🎥 截取视频 / ✂️ 框选区域
在弹窗中选择分类、填写备注，点「上传」或「保存并继续」

👥 分享给好友
你只需要部署一次 GAS，好友使用自己的谷歌账号创建表格和网盘文件夹后：
你在插件「📦 导出」标签点「生成配置」→「复制配置」
好友安装插件后，在「📦 导出」标签粘贴配置 → 点「应用配置」
好友把配置里的表格 ID 和网盘 ID 替换成自己的即可

🎛️ 功能选项说明
表格字段开关
在「🎛️ 选项」标签可以控制表格写入哪些字段：
字段	说明
📥 下载链接	点击直接下载截图文件
📂 打开位置	跳转到 Drive 中的截图所在文件夹
📝 备注栏	截图时填写的随手记内容
🔗 来源链接	跳转回截图来源的原始页面
横排 vs 竖排
模式	表格结构	适合场景
横排（默认）	同一分类的截图从左到右排列	对比同一类素材
竖排	同一分类的截图从上到下排列，新内容在最上方	按时间线浏览

文件	说明
`manifest.json`	插件配置文件
`background.js`	后台服务：截图捕获、GAS 请求转发
`content.js`	注入网页的悬浮工具栏和截图弹窗

`popup.html`	插件弹窗界面
`popup.js`	弹窗逻辑：配置管理、分类管理、导出导入

❓ 常见问题
Q：悬浮工具栏没有出现？
A：配置完成后需要刷新目标网页，工具栏才会加载。
Q：上传失败提示「GAS 配置错误」？
A：检查 GAS 部署时访问权限是否设置为「所有人（含匿名用户）」，每次修改 GAS 代码后需要重新部署新版本。
Q：表格里图片显示不出来？
A：图片通过 Google Drive 缩略图链接加载，需要登录谷歌账号且网络能访问 Drive 才能显示。
Q：好友可以直接用我的 GAS 链接吗？
A：可以。GAS 只负责把截图存到好友填写的自己的网盘和表格里，数据完全隔离，互不影响。
Q：上传后 Sheet 里没看到数据？
A：检查 Sheet 名称是否填写正确（区分大小写），或留空让系统自动写入第一个 Sheet。
